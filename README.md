# Kairos: Your Running Journey

Quiero construir una aplicación web llamada Kairos, una plataforma para corredores enfocada en registrar actividades de running y visualizar su progreso.

Quiero utilizar una interfaz moderna, limpia y profesional, con una estética deportiva. Utiliza un tema oscuro, tipografía clara y acentos dorados.

La aplicación debe tener una barra de navegación lateral y las siguientes secciones:

Dashboard: resumen de la actividad del corredor, incluyendo distancia recorrida, tiempo total, ritmo promedio, objetivo semanal y actividades recientes.

Activities: historial de carreras del usuario y opción para iniciar una nueva carrera.

Progress: estadísticas y gráficas para visualizar la evolución del corredor.

Profile: información del usuario, estadísticas personales y objetivos.

Settings: configuración y preferencias de la cuenta.

Support: sección de ayuda y soporte.

Quiero que todas las secciones tengan navegación funcional entre ellas.

En esta primera etapa, crea la estructura principal de la aplicación, las diferentes páginas y la navegación funcional. Utiliza datos de ejemplo para que las interfaces tengan contenido visible.

Prioriza que la aplicación sea funcional y navegable antes que añadir detalles visuales avanzados.

Mantén una identidad visual consistente en todas las páginas: mismo logo de Kairos, misma tipografía, mismos colores, mismos botones, tarjetas y componentes.

No necesitas implementar todavía un sistema real de autenticación, GPS ni una base de datos. Primero quiero construir la estructura funcional y visual de la aplicación.
